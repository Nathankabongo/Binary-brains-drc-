# Binary Brains DRC - Plateforme Web Officielle

Site web moderne et vitrine technologique de **Binary Brains**, conçu et inspiré des standards d'excellence visuelle et structurelle de plateformes technologiques africaines de référence.

---

## 🚀 Présentation

**Binary Brains** est une initiative technologique basée à Kinshasa (RD Congo), spécialisée dans l'ingénierie locale au service des entreprises et de la société :
- **Internet des Objets (IoT) & Télémétrie** : Conception de systèmes connectés, suivi de flotte d'engins, geofencing (Uber H3, polygones) et prévention des collisions.
- **Cybersécurité & Chiffrement** : Audits de sécurité, durcissement des systèmes, chiffrement des communications et promotion active de la confidentialité des données.
- **Développement Logiciel, Web & Mobile** : Applications modernes, portails métiers, architectures réactives et résilientes.
- **Intelligence Artificielle & Géosciences** : Traitement de données massives, vision par ordinateur et cartographie prédictive.
- **Formations & Événements** : Organisation de hackathons, MasterClasses intensives et célébration de la Journée Mondiale du Chiffrement.

## 🛠️ Installation & Démarrage

### Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure recommandée)
- `npm`

### Lancement en mode développement

```bash
# Cloner le dépôt
git clone https://github.com/Merveille5/binary.git
cd binary

# Installer les dépendances
npm install

# Démarrer le serveur de développement Vite
npm run dev
```

### Compiler pour la production

```bash
npm run build
npm run preview
```
